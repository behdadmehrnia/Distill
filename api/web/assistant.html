پایان جلسه

۱. پردازش ۲. نام‌گذاری سخنگوها ۳. متن جلسه ۴. صورت جلسه

جلسه در حال پردازش نهایی است؛ لطفاً منتظر بمانید.

  • ذخیره فایل صوتی
  • بهبود کیفیت صدا
  • تکمیل پیاده‌سازی متن
  • شناسایی نهایی سخنگوها
  • بهبود نهایی متن

برای هر سخنگو یک نام وارد کنید. پخش نمونه صدا اختیاری است و برای اطمینان بیشتر است.

پیش از تولید صورت جلسه، متن پیاده‌شده را بازبینی کنید؛ روی هر بخش کلیک کنید تا ویرایش شود.
